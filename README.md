# 00Bet -- Versão 1.0
Este é um projeto para a matéria de Projeto Integrado de Sistemas de Informação para Negócios da faculdade UNICEPLAC. 
Se trata de uma extensão para navegadores, cujo objetivo é bloquear sites de aposta, baseando-se em uma lista predefinida. 

## Tecnologias
-HTML
-CSS
-JavaScript

## Estrutura do Projeto
```
extension-00bet/
├── icons/                 # Icones de tamanhos 16,32,64 e 128 para a extensão
├── popup/            
│   ├── popup.js           # Códigos JS para a página da extensão
│   ├── popup.css          # Stylesheet global
│   └── popup.html         # Página HTML da extensão
├── manifest.json          # Documento principal extensão
├── rules.json             # Documento contendo a lista principal de sites que serão bloqueados
└── README.md              # Overview do Projeto (Este arquivo)
```
